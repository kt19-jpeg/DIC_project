DEAD END: FOOTNOTE SYMBOL AS A DATA QUALITY PREDICTOR
================================================================================

Hypothesis:
The dataset uses two footnote symbols — '**' for suppressed/low quality data and '*' for underreported/incomplete data. We expected '**' rows to have significantly more missing Data Values since they're explicitly flagged for quality issues, making the symbol a useful filter for reliable records.

'**' rows (suppressed/quality issues): 68,040
'*'  rows (underreported/incomplete):  13,230

Missing rate for '**' rows: 42.9%
Missing rate for '*'  rows: 34.7%

Conclusion:
The symbol doesn't work as a quality filter the way we expected. '**' rows — flagged for suppression and quality issues — actually have a higher missing rate (42.9%) than '*' rows (34.7%), but the difference isn't meaningful enough to use as a filter. More importantly, ALL rows in this dataset carry one of these two symbols, so the footnote symbol has no discriminating power — it can't separate reliable records from unreliable ones. Dead end.

DEAD END: PERCENT PENDING INVESTIGATION AS A MISSING DATA PREDICTOR
================================================================================

Hypothesis:
Higher 'Percent Pending Investigation' should mean less finalized data, which should mean a higher chance of the Data Value being missing. If true, this column could serve as a useful signal for filtering out unreliable records.

Mean pending % when Data Value IS missing:  0.1804
Mean pending % when Data Value is present:  0.1140
Difference:                                  0.0664

Conclusion:
The relationship exists but is too weak to be useful. Records with missing Data Values have a mean pending rate of 0.1804 vs 0.1140 for present ones — a difference of only 0.0664. That's not nearly enough separation to use this column as a predictor or filter. The missingness in this dataset is driven by CDC suppression rules (counts below 10) and state reporting lags, not by how much is pending investigation. Dead end.
